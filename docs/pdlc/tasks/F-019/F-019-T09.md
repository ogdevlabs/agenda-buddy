threat-model.md T-102 (mitigate now). Force a real internal exception on the failure path of at least one route (e.g. a Mongo write that fails, or an unhandled edge the handler doesn't guard) and inspect the actual wire response's `DataResponse<T>.Errors` array — assert it contains only the intended human-readable message, never `exception.ToString()`, a stack trace fragment, or an internal type name. Real fault injection, not a mocked exception — matches this project's "reasoned, not observed" discipline (episode 001).

AC-13. Relies on Testcontainers' resource reaper (Ryuk). UNVERIFIED - it must be PROVEN by an actual mid-flight kill, not assumed from documentation. This is exactly the 'reasoned, not observed' trap that made threat T-004 wrong in F-013.
Procedure: start a run, kill the test process mid-flight (Ctrl-C equivalent / SIGKILL), then assert docker ps shows ZERO orphan containers.
Directly relevant precedent: at the v0.1.0 ship, killing the AppHost with SIGTERM left SIX orphan service processes and needed a second pkill. Container orphans on a 2 CPU / 4.1 GB VM already running k8s will make later runs fail for unrelated reasons.

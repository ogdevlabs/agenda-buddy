Supports AC-5/6/7 on the provider-registration path. ADR-017: Kafka is NOT containerised.
Justification: Kafka here ONLY creates topics - nothing is produced or consumed (docs/pdlc/context/09-integrations.md). A real broker adds the slowest container in the suite while proving almost nothing, and Kafka startup is materially slower than Mongo's measured 4.45s.
Clean to substitute because IKafkaClient is an interface registered AddSingleton<IKafkaClient, KafkaClient>() (Booking/Program.cs:29, Provider/Program.cs:33). Swap via WebApplicationFactory.ConfigureTestServices.
The fake RECORDS calls so the topic-creation wiring is still asserted - the convention stays guarded, only the broker is faked.

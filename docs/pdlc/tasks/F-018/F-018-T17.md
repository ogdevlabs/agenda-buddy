AC-19. CI regenerates the spec and FAILS when a route changed without regeneration. Demonstrate by deliberately changing one route and observing the failure.
Because the specs are NOT committed in F-018 (ADR-020), the drift baseline is the PREVIOUS run's artifact, or a checked-in hash manifest rather than the spec body. Decide which and record it.

**AMENDED 2026-08-26 (ADR-048, Wave 2 kickoff standup):** ADR-020's commit deferral cleared this session — F-018-T16 already committed byte-deterministic specs to `docs/api/openapi/<service>.json`. The drift baseline is now simply **the committed spec body** — regenerate in CI and diff against the tracked file directly. No previous-run artifact or hash manifest needed; that complexity was only required while specs stayed uncommitted.
MUST be verified on a short-lived THROWAWAY BRANCH pushed by the maintainer on request - main is PR-protected and direct pushes are disallowed. Deliberately NOT downgraded to 'the command passes locally': running a command locally proves the command works, not that CI is wired to run it, which is exactly how F-013's CI credential guard went unexecuted until it first failed on PR #35.
Note threat T-007 (deferred, ADR-020): CI can force regeneration but cannot force anyone to READ the diff. Making that real is F-019/F-020's job.

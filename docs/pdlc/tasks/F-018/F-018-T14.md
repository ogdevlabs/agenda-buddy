AC-9. Uses the TokenFactory from T09.
401: present an EXPIRED token. Only possible because the factory backdates - ClockSkew is TimeSpan.Zero.
403: present a token for a DIFFERENT subject against an ownership-guarded route. Confirmed targets: Booking x3 (OwnershipGuard.AssertOwnerAny), Provider, Services x2, Customer (AssertOwner).
Note for F-016's benefit: OwnershipGuard.AssertRole is never called anywhere, and Calendar's two routes are authenticated but NOT ownership-guarded (an IDOR). Do not 'fix' either here - F-018 changes no production behaviour. Just do not write a test that asserts the broken behaviour is correct.

Deletes SeedDataProvider and every fallback call to it (DashboardViewModel.LoadAsync, CalendarViewModel's equivalent). Fixes the two bugs the fallback was hiding: ErrorMessage is currently hardcoded to string.Empty and never reassigned (HasError can never be true); a zero-length result is currently replaced by seed data before being assigned (IsEmpty can never be true). Both become reachable the moment the interception is removed — this task is what actually exercises them for the first time since F-012 shipped.
Depends on F-015-T07: the error banner and empty state are meaningless to wire until the calls feeding them return real 2xx/error responses instead of a 404 that always looked like "no data, use seed."

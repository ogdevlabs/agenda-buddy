Adds the eighth resource to AppHostWiring.cs following the AddApi<TProject> helper pattern already used for all seven services: `builder.AddProject<Projects.Gateway>("gateway", launchProfileName: null)`, then `WithReference`/`WaitFor` on all seven, matching how the AppHost already composes MongoDB and Kafka. `WithReference` is what injects the `services__<name>__http__0` keys F-015-T02/T03 read; `WaitFor` on all seven means the gateway only reports healthy once every destination it could route to is also healthy.
AC3/AC4 land here rather than on the routing tasks because this is the first point at which a full request can flow client→gateway→destination end to end — auth passthrough is a property of NOT adding gateway-side auth middleware (a negative), and this task is what makes that provable against a real service rather than a stub.
New AppHost model tests, mirroring the existing AppHostWiringTest pattern.

run-ios.sh already discovers each service's dynamically-assigned port by probing /alive across every port a PID listens on — today it only prints the result for a human. Extends the same probe loop to also find the gateway's port, and injects it into the simulator process as MAUI_API_BASE_URL, which MauiProgram.cs reads in place of the hardcoded http://localhost:6036/ fallback (Design Round 1, Q2) — reusing an existing mechanism rather than inventing a new one.
AC6 lands here because this is the task that actually exercises an AppHost restart against a running client: the script's discovery loop must re-resolve the gateway's port if the AppHost is restarted mid-session, proving the live-per-request resolution F-015-T02/T03 built survives the scenario end to end, not just in a unit test.
Depends on F-015-T05 — there must be a gateway resource in the AppHost for this script to discover.

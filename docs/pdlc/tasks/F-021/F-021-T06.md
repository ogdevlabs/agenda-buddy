Threat T-101, and the measurement that inverted this feature's premise: BCrypt verify at work factor 12 costs 262 ms on this hardware, so password guessing runs at 3.8 attempts/sec/core — while the same cost means every unauthenticated login or register request BUYS 262 ms of server CPU, so ~4 req/sec pins a core. Identity issues the tokens all six other services validate, so that is a full auth outage from one host.
Covers register as well as login (D-4): RegisterAsync hashes at the same work factor. Does NOT cover refresh: no BCrypt, and throttling it would break a legitimate client's hourly rotation. Both asserted.
Per-IP in middleware, per-account in IdentityService (D-3): ASP.NET resolves a partition key from HttpContext BEFORE model binding and the account is in the JSON body. The two halves are not redundant — the dummy-hash enumeration mitigation (T-005) means an attacker using random addresses generates no per-account state at all, so only the limiter sees them.
Registered FIRST in the pipeline, which is the whole point: a throttled request must cost no CPU and take no write. Threat T-102's ordering requirement is asserted through the counter — a throttled request moves it by zero.
RejectionStatusCode is set to 429 explicitly; the framework's default is 503, which says "this service is broken" and gives a client nothing to back off from. Retry-After falls back to the window length when the lease carries no metadata, because PRD requirement 12 makes it mandatory.
PermitPerMinute is clamped to >= 1: a configured 0 makes SlidingWindowRateLimiterOptions throw at the first request, turning a typo in a value that exists to be changed without a deploy into a total login outage.
AppHost half (ADR-033, threat T-103): Security__Local=true locally so services know "off" is deliberate and log no warning; Security__Hsts__Enabled=true for all seven and Security__RateLimiting__Enabled=true for identity in the cloud graph. That is the only artifact distinguishing "the feature was written" from "the feature is switched on" — the distinction F-016's original defect failed.

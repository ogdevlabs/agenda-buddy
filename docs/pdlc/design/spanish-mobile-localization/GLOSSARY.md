# Spanish Product Glossary

**Locale:** `es-MX`, neutral Latin-American wording
**Voice:** direct, warm, concise; use informal singular `tú` consistently

| English concept | Spanish term | Guidance |
|---|---|---|
| appointment | cita | Use for a scheduled provider/customer meeting |
| booking / to book | reserva / reservar | Use for the act of choosing a slot |
| provider | profesional | Avoid “proveedor,” which reads as a supplier rather than a person |
| customer | cliente | Use consistently across contact and booking flows |
| service | servicio | A provider’s bookable offering |
| availability | disponibilidad | Free times a customer may choose |
| working week | semana laboral | Provider-configured open days and hours |
| time off | tiempo no disponible | Provider-only block; avoid implying paid employment leave |
| reschedule | reprogramar | Use for changing an appointment time |
| session | sesión | Use when discussing the delivered meeting, notes, or duration |
| notification | notificación | In-app or push notice |
| profile | perfil | User’s customer/provider information |
| sign in / sign out | iniciar sesión / cerrar sesión | Authentication actions |
| Terms and Conditions | Términos y condiciones | Legal document title |
| Privacy Policy | Política de privacidad | Legal document title; consent copy may say “Aviso” only after legal approval |

Canonical API values remain English and are never translated on the wire.
